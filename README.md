Aplicação web desenvolvida durante o Hackathon CREA Júnior para apoio à preparação profissional de estudantes. O sistema realiza análise de currículos enviados pelos usuários, gera feedback automatizado sobre sua qualidade e utiliza reconhecimento de voz para simulação de entrevistas personalizadas com base nas informações presentes no currículo. Desenvolvido com React no front-end e Python no back-end.
